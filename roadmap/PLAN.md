## Недельный ритм

Ориентир для активной недели — **18 часов**:

| День | Часы | Что делать |
|---|---|---|
| Пн–Чт | 2 | новая теория + короткая практика |
| Пт | 1 | разбор ошибок и заметок |
| Сб | 5 | практика: ноутбук, задачи, проект |
| Вс | 4 | сессия с тьютором, конспект, повторение |

В сессию и на праздниках — **8–12 часов**: только повторение, долги и мок-собесы. Минимум, ниже которого неделя считается проваленной, — 8 часов.

## Приоритеты по этапам

1. **База (1–6).** Математика — главное. Python Base и алгоритмы — параллельно. Git/Linux проходим быстро: многое уже знакомо, лишнее закрывается диагностикой.
2. **Classic ML (7–11).** Не начинать заново: текущие конспекты A1/A2 уже дают часть материала. Добиваем метрики, валидацию, деревья, ансамбли, sklearn.
3. **Deep Learning (12–17).** Сначала backprop и оптимизаторы, потом внимание и трансформеры. PyTorch-проект — обязательный результат этапа.
4. **NLP/LLM (18–29).** Идти по цепочке: тексты → эмбеддинги → языковые модели → трансформеры → архитектуры LLM → оптимизация → RAG.
5. **Резюме, MLSD, агенты (30–35).** Проекты уже должны быть; здесь они упаковываются в истории и резюме.
6. **Выход на рынок (36).** Профили, банк вопросов, отклики, мок-собесы.
