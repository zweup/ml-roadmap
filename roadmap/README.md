# Роадмап ML 2026

Личная адаптация роадмапа «ML 2026»: 45 недель, 789 тем и 7 мок-собеседований, разложенных по неделям и связанных с конспектами и сократовским тьютором.

Источник: [schmidtml.ru](https://schmidtml.ru) · [@solyianka](https://t.me/solyianka). Оригинальный HTML лежит в [`source/roadmap-ml-2026.html`](source/roadmap-ml-2026.html), условия использования — в [`source/README.md`](source/README.md).

## Коротко

- **45 недель:** 36 обязательных + 9 дополнительных.
- **646 обязательных часов** и ещё 140 часов в дополнительных неделях.
- **789 тем**, из них **568 ядерных** — их проходим в первую очередь.
- **7 мок-собеседований:** недели 6, 11, 15, 27, 29, 32, 35.
- **Старт:** 23.11.2026. **Финиш обязательной части:** 12.09.2027 (42 календарные недели с 6 буферами).

## Как пользоваться

1. Откройте [`PLAN.md`](PLAN.md) — там календарь, буферы, недельная нагрузка и проекты.
2. Откройте файл текущей недели в [`weeks/`](weeks/).
3. Первый проход — только ядро. Темы с пометками `дополнительно`, `ресерч`, `можно позже` откладываются.
4. В конце недели проведите сессию с тьютором: диагностика, 4–8 поднавыков, уровень ≥3.
5. Ставьте `[x]` только после проверки, а не после чтения. Конспект — в [`ml-learning/`](../ml-learning/README.md).
6. Раз в неделю запускайте `python3 scripts/roadmap_progress.py` — dashboard ниже обновится сам.

## Правила

- **Ядро важнее объёма.** Если неделя провалена, режем `дополнительно` и `ресерч`, а не ядерные темы.
- **18 часов в активную неделю** — ориентир. В сессию и на праздниках — 10–12 часов, буферы для этого и нужны.
- **`[x]` = уровень ≥3.** Уровни: `0` не знаю · `1` слышал · `2` понимаю по объяснению · `3` могу с помощью · `4` могу сам · `5` могу учить других.
- **Одна тема — один конспект.** Коротко: главное, пример, заблуждения, что нужно для 4/5.
- **Проекты не откладываются:** недели 10, 17, 28, 34 — контрольные точки в [`projects/`](../projects/README.md).
- **Мок-собесы не пропускаются:** недели 6, 11, 15, 27, 29, 32, 35.
