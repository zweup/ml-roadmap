# A2. Линейная регрессия

Уровень: **3/5**. Статус: в работе; открытый вопрос по градиентному спуску ещё не отвечен.

## Формула модели

```text
ŷ = w · x + b
```

- `x` — признак (например, площадь);
- `ŷ` — предсказание модели;
- `w` — вес: насколько сильно предсказание меняется при росте `x`;
- `b` — сдвиг: значение `ŷ` при `x = 0`, точка пересечения прямой с осью.

Проверка из разбора: при `x = 54`

- `w = 10, b = 0` → `ŷ = 540`;
- `w = 20, b = 0` → `ŷ = 1080`.

Увеличение `w` увеличивает **предсказание**, а не «количество ошибок».

Про `b`: при `w` и `x` одинаковых модель с `b = 0` и модель с `b = 100` отличаются на 100. Если `b = 100`, то для `x = 0` предсказание равно 100 млн ₽ — на первый взгляд нелепо, но квартир нулевой площади не бывает, поэтому формула имеет смысл на диапазоне реальных площадей.

## Функция ошибки MSE

Чтобы подобрать `w` и `b`, нужно уметь оценивать качество предсказаний. Для каждого старого объявления:

```text
ошибка = ŷ − y
MSE = среднее по всем объектам от (ŷ − y)²
```

Пример из разбора, пять объектов:

- модель А: `50² + 0 + 0 + 0 + 0 = 2500`;
- модель Б: `5 · 10² = 500`.

По модулю обе модели дают `50` — разницы не видно. Квадрат делает один крупный промах намного дороже многих мелких: `2500 > 500`. Поэтому модель стремится избегать больших ошибок.

Следствие: одна опечатка в цене (`ошибка 100`) для MSE — критическая ошибка. Модель попытается уменьшить её, изменив `w` и `b`. **Сама таблица при этом не меняется** — меняются только параметры формулы.

## Градиентный спуск (введение)

Модель начинает со случайных `w` и `b` и шаг за шагом сдвигает их в сторону уменьшения MSE. Направление шага подсказывает производная функции ошибки. Этот процесс называется градиентный спуск.

Открытый вопрос сессии: мы пробовали `w = 10` и `w = 20`, и при `w = 20` ошибка выросла. Куда сделает следующий шаг градиентный спуск?

## Заблуждения, которые разобрали

- «Больше `w` → больше ошибок». На самом деле больше `w` → больше предсказание при том же `x`.
- «В MSE достаточно модуля». Модуль не различает один промах на 50 и пять промахов по 10.
- Арифметическая оговорка: `15² = 225`, не 255.
- «Модель меняет данные». Она меняет только `w` и `b`.
- Аналогия с разбросом в шутере была не про `w`, а про ошибки; верная аналогия — с зазубриванием маршрута (см. A1).
