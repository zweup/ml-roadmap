# A1. Постановка задачи

Уровень: **3/5**. Статус: в работе (до 4/5 нужно объяснить задачу и train/test без подсказки).

## Главное

В обучении с учителем есть старые примеры с уже известными ответами. У каждого примера две части:

- **признаки** (features) — что мы знаем заранее: площадь, этаж, район;
- **цель** (target) — что хотим предсказать: цена квартиры.

Модель ищет правило «признаки → цель» по старым объявлениям, чтобы применить его к новым.

## Прямая и обратная задача

Мы решаем **прямую** задачу: знаем площадь/этаж/район, предсказываем цену.

Обратная задача — угадывать характеристики по цене — возможна, но это другая задача. Она не решает нашу проблему: по одной и той же цене могут быть разные квартиры (20 м² в центре и 100 м² в спальнике).

Если в таблице есть только столбец «цена» и больше ничего, модель не может предсказать новую квартиру: нечего подавать на вход.

## Обобщение, а не lookup

Если сочетания признаков не было в таблице, модель не ищет готовую запись, а **интерполирует** по соседним примерам:

```text
известно:  ошибка 1 ......... ошибка 3
нужное:    ошибка x между ними → оценка около (1 + 3) / 2 = 2
```

То есть модель строит правило по соседям, а не таблицу всех возможных сочетаний.

## Обучение и проверка

Чтобы модель можно было обучить, нужны исторические пары «признаки → известная цена».

Исходную таблицу (например, 1000 объявлений) делят на две части:

- **обучающая** — модель видит ответы и подстраивается под них;
- **проверочная** — ответы скрыты, по ним считают долю правильных предсказаний или количество ошибок.

Например, 500 на 500. Проверять на обучающей части нельзя: она покажет почти идеальный результат, потому что модель запомнила ответы.

## Переобучение

Аналогия из разбора: если гонять модель только по одной дороге, она зазубривает конкретный маршрут и проезжает его идеально. На другой дороге она едет намного хуже, потому что маршрут для неё новый.

Это и есть переобучение: идеально на старых данных, плохо на новых. Поэтому нужна отложенная проверочная выборка.

## Заблуждения, которые разобрали

- «Целевая переменная — квартира». На самом деле квартира — объект, а цель — её цена.
- «Модель предсказывает характеристики по цене». Это обратная задача.
- «Модель меняет данные». Модель меняет только свои параметры (см. A2).

## Что нужно для 4/5

Самому, без наводящих вопросов, сформулировать: что является признаками, что целью, зачем нужны исторические пары и зачем откладывать часть данных для проверки.
