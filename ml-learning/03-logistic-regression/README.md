# A3. Логистическая регрессия

Уровень: **0/5**. Статус: не начато.

Здесь будет конспект по классификации: вероятность на выходе модели, сигмоида, функция потерь и выбор порога.

Из ранней диагностики (до обнуления курса) понималось: модель полезно выдавать число от 0 до 1, а не готовую метку; порог 0,5 — не догма, его выбирают исходя из цены ошибки. После обнуления тема пройдёт заново.
