## Математический анализ: Пределы, бесконечно малые функции и непрерывность


## 1. Односторонние пределы

Пусть функция $y = f(x)$ определена в некоторой окрестности точки $a$.

## Направления стремления аргумента

- Правый предел: Аргумент $x$ приближается к $a$ справа ($x > a$, обозначается как $x \to a + 0$).
- Левый предел: Аргумент $x$ приближается к $a$ слева ($x < a$, обозначается как $x \to a - 0$).

```unset
Левый предел (x -> a - 0):          Правый предел (x -> a + 0):
 ------------------------> [ a ] <------------------------
          x < a                                    x > a
```

## Определение по Гейне (через последовательности)

- Число $b$ называется правым (левым) пределом функции $f(x)$ в точке $a$, если для любой последовательности $\{x_n\} \to a$, такой что $x_n > a$ для правого (или $x_n < a$ для левого), соответствующая последовательность значений функции $\{f(x_n)\} \to b$.
- Обозначения:
    
    - Правый предел: $\lim_{x \to a + 0} f(x) = b$ или $f(a + 0)$
    - Левый предел: $\lim_{x \to a - 0} f(x) = b$ или $f(a - 0)$
    - Сокращенная запись для нулевой точки: $f(+0)$ и $f(-0)$.
    

## Определение по Коши (на языке $\varepsilon - \delta$)

- Правый предел:  
    $$\forall (\varepsilon > 0)\ \exists \delta = \delta_\varepsilon > 0 : \forall x: a < x < a + \delta \implies \vert{}f(x) - b\vert{} < \varepsilon$$
- Левый предел:  
    $$\forall (\varepsilon > 0)\ \exists \delta = \delta_\varepsilon > 0 : \forall x: a - \delta < x < a \implies \vert{}f(x) - b\vert{} < \varepsilon$$

> [!NOTE] Эквивалентность  
> Указанные определения по Гейне и по Коши полностью эквивалентны.

## Признаки и условия существования предела

> [!THEOREM] Необходимое и достаточное условие (Критерий существования)  
> Двусторонний предел функции $\lim_{x \to a} f(x) = b$ существует тогда и только тогда, когда в этой точке существуют оба односторонних предела и они равны между собой:  
> $$\lim_{x \to a} f(x) = b \iff f(a - 0) = f(a + 0) = b$$

- Общее определение двустороннего предела по Коши:  
    $$\forall (\varepsilon > 0)\ \exists \delta = \delta_\varepsilon > 0 : \forall x: 0 < \vert{}x - a\vert{} < \delta \implies \vert{}f(x) - b\vert{} < \varepsilon$$

## 2. Основные теоремы о пределах (Арифметика пределов)

Пусть заданы функции $f(x)$ и $g(x)$. Если существуют конечные пределы $\lim_{x \to a} f(x) = b$ и $\lim_{x \to a} g(x) = c$, то выполняются следующие свойства:

1. Предел суммы и разности:  
    $$\lim_{x \to a} (f(x) \pm g(x)) = \lim_{x \to a} f(x) \pm \lim_{x \to a} g(x) = b \pm c$$
2. Предел произведения:  
    $$\lim_{x \to a} (f(x) \cdot g(x)) = \lim_{x \to a} f(x) \cdot \lim_{x \to a} g(x) = b \cdot c$$
3. Предел частного (при условии $c \neq 0$):  
    $$\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{\lim_{x \to a} f(x)}{\lim_{x \to a} g(x)} = \frac{b}{c}$$

## Доказательство через определение по Гейне:

Возьмем произвольную последовательность $\{x_n\} \to a$, где $x_n \neq a$. По условию существования пределов функций имеем: $\{f(x_n)\} \to b$ и $\{g(x_n)\} \to c$. Тогда по свойствам пределов числовых последовательностей:

- $\{f(x_n) \pm g(x_n)\} \to b \pm c$
- $\{f(x_n) \cdot g(x_n)\} \to b \cdot c$
- $\left\{\frac{f(x_n)}{g(x_n)}\right\} \to \frac{b}{c}$ (при $c \neq 0$)

Из сходимости этих последовательностей значений, согласно определению Гейне, вытекают соответствующие равенства для пределов функций.

## 3. Теорема Гурьева (Теорема о сжатой переменной / «О двух милиционерах»)

> [!THEOREM] Теорема о зажатой функции  
> Пусть в некоторой окрестности предельной точки $a$ заданы три функции $f(x)$, $g(x)$ и $h(x)$, связанные неравенством:  
> $$g(x) \le f(x) \le h(x) \quad (*)$$  
> Если функции на краях стремятся к одному и тому же конечному пределу $\lim_{x \to a} g(x) = \lim_{x \to a} h(x) = b$, то функция внутри также имеет предел, равный $b$:  
> $$\lim_{x \to a} f(x) = b$$

## Доказательство:

1. Запишем определение предела по Коши для функции $g(x)$:  
    $$\forall (\varepsilon > 0)\ \exists \delta_1 > 0 : 0 < \vert{}x - a\vert{} < \delta_1 \implies \vert{}g(x) - b\vert{} < \varepsilon \iff b - \varepsilon < g(x) < b + \varepsilon$$
2. Запишем определение предела по Коши для функции $h(x)$:  
    $$\forall (\varepsilon > 0)\ \exists \delta_2 > 0 : 0 < \vert{}x - a\vert{} < \delta_2 \implies \vert{}h(x) - b\vert{} < \varepsilon \iff b - \varepsilon < h(x) < b + \varepsilon$$
3. Выберем общую окрестность, взяв минимальное смещение: $\delta = \min(\delta_1, \delta_2)$.
4. Тогда при условии $0 < \vert{}x - a\vert{} < \delta$ одновременно выполняются все неравенства:  
    $$b - \varepsilon < g(x) \le f(x) \le h(x) < b + \varepsilon \implies b - \varepsilon < f(x) < b + \varepsilon$$
5. Следовательно, $\forall (\varepsilon > 0)\ \exists \delta_3 > 0 : \forall x: 0 < \vert{}x - a\vert{} < \delta_3 \implies \vert{}f(x) - b\vert{} < \varepsilon$, что доказывает равенство $\lim_{x \to a} f(x) = b$.

## 4. Бесконечно малые функции (БМФ)

> [!DEFINITION] Определение БМФ  
> Функция $\alpha(x)$ называется бесконечно малой при $x \to a$, если её предел в этой точке равен нулю:  
> $$\lim_{x \to a} \alpha(x) = 0$$  
> Формальная запись на языке Коши:  
> $$\forall (\varepsilon > 0)\ \exists \delta = \delta_\varepsilon > 0 : \forall x: 0 < \vert{}x - a\vert{} < \delta \implies \vert{}\alpha(x)\vert{} < \varepsilon$$

## Основные свойства БМФ:

- Произведение БМФ на ограниченную функцию ($\vert{}f(x)\vert{} \le M$ на некотором множестве $G$) при $x \to a$ является бесконечно малой функцией.
- Произведение БМФ на константу ($\text{const} \cdot \alpha(x)$) является бесконечно малой функцией.

---

## 5. Сравнение бесконечно малых функций

Пусть $\alpha(x)$ и $\beta(x)$ — бесконечно малые функции при $x \to a$. Сравнение их скоростей стремления к нулю производится с помощью исследования предела их отношения $\lim_{x \to a} \frac{\alpha(x)}{\beta(x)} = c$:

1. ** Более высокий порядок малости ($c = 0$):**  
    Если предел отношения равен $0$, то $\alpha(x)$ является БМФ более высокого порядка малости по сравнению с $\beta(x)$.
    
    - Запись через «о-малое»: $\alpha(x) = o(\beta(x))$.
    
2. Один порядок малости ($c \neq 0, c \neq 1$):  
    Функции стремятся к нулю с сопоставимой скоростью. Обозначается как $\alpha(x) = O(\beta(x))$ и $\beta(x) = O(\alpha(x))$.
3. Эквивалентные БМФ ($c = 1$):  
    Если предел отношения равен $1$, то функции называются эквивалентными БМФ.
    
    - Запись: $\alpha(x) \sim \beta(x)$.
    

## Теорема об эквивалентности БМФ

> [!THEOREM] Критерий эквивалентности (Необходимое и достаточное условие)  
> Две БМФ $\alpha(x)$ и $\beta(x)$ эквивалентны ($\alpha(x) \sim \beta(x)$) тогда и только тогда, когда их разность является бесконечно малой более высокого порядка малости:  
> $$\alpha(x) - \beta(x) = o(\alpha(x)) \quad \text{или } o(\beta(x))$$

## Доказательство необходимости:

Дано, что $\alpha(x) \sim \beta(x) \implies \lim_{x \to a} \frac{\beta(x)}{\alpha(x)} = 1$. Рассмотрим предел:  
$$\lim_{x \to a} \frac{\alpha(x) - \beta(x)}{\alpha(x)} = \lim_{x \to a} \left(\frac{\alpha(x)}{\alpha(x)} - \frac{\beta(x)}{\alpha(x)}\right) = 1 - 1 = 0 \implies \alpha(x) - \beta(x) = o(\alpha(x))$$

## Доказательство достаточности:

Дано, что $\alpha(x) - \beta(x) = o(\alpha(x)) \implies \lim_{x \to a} \frac{\alpha(x) - \beta(x)}{\alpha(x)} = 0$. Тогда:  
$$\lim_{x \to a} \left(1 - \frac{\beta(x)}{\alpha(x)}\right) = 0 \implies 1 - \lim_{x \to a} \frac{\beta(x)}{\alpha(x)} = 0 \implies \lim_{x \to a} \frac{\beta(x)}{\alpha(x)} = 1 \implies \beta(x) \sim \alpha(x)$$

## Пример раскрытия неопределенности из тетради:

Вычислить предел с помощью замены на эквивалентные бесконечно малые при $x \to 0$:  
$$\lim_{x \to 0} \frac{\sin 5x}{\ln(1 + 3x)} = \left[ \text{так как } \sin 5x \sim 5x, \ \ln(1 + 3x) \sim 3x \right] = \lim_{x \to 0} \frac{5x}{3x} = \frac{5}{3}$$

## 6. Дополнительные свойства пределов

## Теорема о связи предела и БМФ

$$\lim_{x \to a} f(x) = b \iff f(x) = b + \alpha(x), \quad \text{где } \lim_{x \to a} \alpha(x) = 0$$

## Предел на бесконечности ($x \to \infty$)

- По Коши: $\lim_{x \to \infty} f(x) = b \iff \forall (\varepsilon > 0)\ \exists M > 0 : \forall x : x > M \implies \vert{}f(x) - b\vert{} < \varepsilon$
- По Гейне: $\lim_{x \to \infty} f(x) = b \iff \forall \{x_n\} \to +\infty \implies \{f(x_n)\} \to b$

## Связь БМФ и ББФ (Бесконечно больших функций)

Если $\alpha(x)$ — бесконечно малая функция при $x \to a$, то обратная ей функция $A(x) = \frac{1}{\alpha(x)}$ является бесконечно большой ($\lim_{x \to a} A(x) = \infty$). Справедливо и обратное: если $A(x)$ — ББФ, то $\alpha(x) = \frac{1}{A(x)}$ — БМФ.

## 7. Непрерывность функций

> [!DEFINITION] Определение непрерывности в точке  
> Функция $y = f(x)$ называется непрерывной в точке $a$, если одновременно выполняются следующие три условия:
> 
> 1. Точка $a$ входит в область определения функции: $a \in D(f)$.
> 2. Существует конечный двусторонний предел функции при стремлении аргумента к $a$: $\exists \lim_{x \to a} f(x)$.
> 3. Значение этого предела совпадает с непосредственным значением функции в точке $a$:  
>     $$\lim_{x \to a} f(x) = f(a)$$

## Свойство элементарных функций

Все базовые элементарные функции (например, многочлены $y = x^n + p_1 x^{n-1} + \dots + p_n$, показательные функции $y = a^x$ при $a>0, a\neq1$, логарифмы $y = \log_a x$ при $x>0, a>0, a\neq1$) являются непрерывными во всех точках своей области определения.

Если функция определена на отрезке, то её непрерывность на множестве обозначается символом класса: $f(x) \in C[a, b]$.

## Пример функции с точкой разрыва из тетради:

Рассмотрим кусочно-заданную функцию:  
$$f(x) = \begin{cases} x^2, & x \in (0, 1] \\ 1, & x = 0 \end{cases}$$

При $x \to 0 + 0$ предел функции равен $\lim_{x \to 0+0} x^2 = 0$. Однако значение функции в самой точке $f(0) = 1$. Поскольку предел не совпадает со значением в точке ($\lim_{x \to 0+0} f(x) \neq f(0)$), функция терпит разрыв в точке $x = 0$.
