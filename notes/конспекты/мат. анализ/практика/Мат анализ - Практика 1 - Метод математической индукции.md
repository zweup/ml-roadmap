## Сумма первых $n$ натуральных чисел

$$1+2+3+\dots+n = \frac{n(n+1)}{2}$$

### Вывод через формулу арифметической прогрессии

Последовательность $1,2,3,\dots,n$ — арифметическая прогрессия с $a_1=1$ и разностью $d=1$. Общий член:
$$a_n = a_1+d(n-1)$$

Сумма первых $n$ членов арифметической прогрессии:
$$S_n = \frac{a_1+a_n}{2}\cdot n = \frac{a_1+\big(a_1+(n-1)d\big)}{2}\cdot n$$

### Вывод "трюком Гаусса" — на конкретном примере

Посчитаем $S_{100} = 1+2+\dots+100$ без формулы:

$$S_{100} = 1+2+\dots+100$$
$$S_{100} = 100+99+\dots+1 \quad \text{(та же сумма, записанная в обратном порядке)}$$

Сложим эти две записи **почленно** — каждая пара даёт одну и ту же сумму $101$:

$$2S_{100} = \underbrace{101+101+\dots+101}_{100 \text{ раз}} = 101\cdot100$$

$$S_{100} = \frac{101\cdot100}{2} = 5050$$

> [!tip] Тот же трюк в общем виде
> $$2S_n = n\cdot(a_1+a_n) \implies S_n = \frac{a_1+a_n}{2}\cdot n$$
> Это ровно формула суммы арифметической прогрессии — трюк Гаусса просто показывает, **откуда** она берётся.

## Метод математической индукции

Метод доказательства утверждений вида "для всех натуральных $n$ верно $P(n)$" из трёх шагов:

1. **База индукции** — проверить утверждение для $n=1$ (простейший случай)
2. **Индукционное предположение** — предположить, что утверждение верно для $n=k$ (какого-то конкретного, но произвольного числа)
3. **Индукционный переход** — доказать, что из истинности при $n=k$ следует истинность при $n=k+1$

> [!tip] Аналогия с падающими доминошками
> Если первая доминошка падает (база), и из падения любой доминошки следует падение следующей (переход), то упадут **все** доминошки подряд — сколько бы их ни было. Именно это и доказывает метод индукции: не проверка каждого $n$ по отдельности, а именно "цепная реакция".

## Пример 1. Доказать $S_n = 1+2+\dots+n = \dfrac{n(n+1)}{2}$

**1) База индукции** ($n=1$):
$$S_1 = 1, \qquad \frac{1\cdot(1+1)}{2} = 1 \quad \checkmark$$

**2) Предположение**: пусть при $n=k$ формула верна:
$$S_k = \frac{k(k+1)}{2}$$

**3) Переход**: докажем, что тогда при $n=k+1$:
$$S_{k+1} = \frac{(k+1)(k+2)}{2}$$

**Доказательство:**
$$S_{k+1} = S_k + (k+1) = \frac{k(k+1)}{2} + (k+1) = (k+1)\left(\frac{k}{2}+1\right) = \frac{(k+1)(k+2)}{2}$$

**Доказано.** $\blacksquare$

> [!tip] Общая схема перехода
> Заметь приём: $S_{k+1} = S_k + (\text{новое слагаемое})$. Ты подставляешь предположение шага 2 вместо $S_k$, а дальше — чисто алгебраическое упрощение до нужного вида. Это работает почти во всех задачах на индукцию для сумм.

## Пример 2. Доказать $1^2+2^2+3^2+\dots+n^2 = \dfrac{n(n+1)(2n+1)}{6}$

**1) База** ($n=1$): $S_1=1$, формула: $\dfrac{1\cdot2\cdot3}{6}=1$ ✓

Проверим ещё для $n=2$: $S_2 = 1^2+2^2 = 5$, формула: $\dfrac{2\cdot3\cdot5}{6}=5$ ✓ (необязательный шаг, просто для уверенности перед переходом к общему случаю)

**2) Предположение**: пусть при $n=k$:
$$S_k = \frac{k(k+1)(2k+1)}{6}$$

**3) Переход**: докажем для $n=k+1$:
$$S_{k+1} = \frac{(k+1)(k+2)(2k+3)}{6}$$

**Доказательство:**
$$S_{k+1} = S_k + (k+1)^2 = \frac{k(k+1)(2k+1)}{6} + (k+1)^2$$

Приводим к общему знаменателю:
$$= \frac{k(k+1)(2k+1) + 6(k+1)^2}{6} = \frac{(k+1)\big[k(2k+1) + 6(k+1)\big]}{6}$$

Раскрываем скобки внутри:
$$k(2k+1)+6(k+1) = 2k^2+k+6k+6 = 2k^2+7k+6$$

Замечаем, что $2k^2+7k+6 = (k+2)(2k+3)$ (проверка: $(k+2)(2k+3) = 2k^2+3k+4k+6 = 2k^2+7k+6$ ✓)

$$S_{k+1} = \frac{(k+1)(k+2)(2k+3)}{6}$$

**Доказано.** $\blacksquare$

## Пример 3. Доказать $1+2+2^2+\dots+2^{n-1} = 2^n-1$

Удобнее переписать сумму, начиная степени с нуля:
$$2^0+2^1+2^2+\dots+2^{n-1} = 2^n-2^0$$

**1) База** ($n=1$): $S_1 = 2^0 = 1$, формула: $2^1-1=1$ ✓

**2) Предположение**: пусть при $n=k$:
$$S_k = 2^k-1$$

**3) Переход**: докажем для $n=k+1$:
$$S_{k+1} = 2^{k+1}-1$$

**Доказательство:** последнее слагаемое суммы при $n=k+1$ — это $2^{(k+1)-1}=2^k$:
$$S_{k+1} = S_k + 2^k = (2^k-1)+2^k = 2\cdot2^k-1 = 2^{k+1}-1$$

**Доказано.** $\blacksquare$

## Домашнее задание: доказать $1^3+2^3+3^3+\dots+n^3 = (1+2+3+\dots+n)^2$

> [!question] Условие
> Докажи это тождество методом математической индукции самостоятельно. Ниже — полный разбор для самопроверки, но попробуй сначала сам, используя ту же трёхшаговую схему, что и в примерах выше.

Заметим сразу: правая часть — это просто $\left(\dfrac{n(n+1)}{2}\right)^2$, так как $1+2+\dots+n=\dfrac{n(n+1)}{2}$ (формула из начала конспекта).

**1) База** ($n=1$): $1^3=1$, а $\left(\dfrac{1\cdot2}{2}\right)^2 = 1$ ✓

**2) Предположение**: пусть при $n=k$:
$$1^3+2^3+\dots+k^3 = \left(\frac{k(k+1)}{2}\right)^2$$

**3) Переход**: докажем для $n=k+1$:
$$1^3+\dots+k^3+(k+1)^3 = \left(\frac{(k+1)(k+2)}{2}\right)^2$$

**Доказательство:**
$$S_{k+1} = S_k+(k+1)^3 = \left(\frac{k(k+1)}{2}\right)^2 + (k+1)^3 = (k+1)^2\left[\frac{k^2}{4}+(k+1)\right]$$

Приводим скобку к общему знаменателю:
$$\frac{k^2}{4}+(k+1) = \frac{k^2+4(k+1)}{4} = \frac{k^2+4k+4}{4} = \frac{(k+2)^2}{4}$$

Подставляем обратно:
$$S_{k+1} = (k+1)^2\cdot\frac{(k+2)^2}{4} = \left(\frac{(k+1)(k+2)}{2}\right)^2$$

Это ровно то, что требовалось — формула для $n=k+1$. **Доказано.** $\blacksquare$

## Итог

- Метод математической индукции — три шага: **база**, **предположение**, **переход** (из $n=k$ доказать $n=k+1$)
- Ключевой приём в переходе: $S_{k+1} = S_k + (\text{новое слагаемое})$, подставить предположение и упростить алгебраически до нужного вида
- Разобранные формулы стоит просто запомнить — они часто нужны как готовый инструмент в других задачах:
  - $1+2+\dots+n = \dfrac{n(n+1)}{2}$
  - $1^2+2^2+\dots+n^2 = \dfrac{n(n+1)(2n+1)}{6}$
  - $1+2+2^2+\dots+2^{n-1} = 2^n-1$
  - $1^3+2^3+\dots+n^3 = \left(\dfrac{n(n+1)}{2}\right)^2$
