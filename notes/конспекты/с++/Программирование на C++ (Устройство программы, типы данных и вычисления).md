# Введение в C++: Устройство программы, типы, память и условное выполнение

## 1. Базовые понятия исходного кода и синтаксиса

* **Природа языка:** Язык C++ является **компилируемым**. Исходный код переводится компилятором в машинные инструкции.
* **Регистрозависимость:** Язык строго чувствителен к регистру символов. Идентификаторы `vova` и `Vova` абсолютно различны.
* **Идентификаторы (Правила именования):**
  - Не могут начинаться с цифры (например: `4vova` — *невалидный идентификатор*).
  - Не содержат пробелов, дефисов и спецсимволов (например: `vovo4ka-smirnov` — *невалидный идентификатор*).
  - Разрешено использование символа подчеркивания (например: `vovo4ka_smirnov` — *валидный*).
  - Не могут являться зарезервированными ключевыми словами (например: `return`, `int`).

### Валидные и невалидные примеры из тетради:
* `vova` — Валидный
* `vovo4ka` — Валидный
* `vovo4ka-smirnov` — **Невалидный** (содержит дефис)
* `vovo4ka_smirnov` — Валидный
* `4vova` — **Невалидный** (начинается с цифры)
* `return` — **Невалидный** (ключевое слово)

## 2. Модель памяти и жизненный цикл переменных

### Модель памяти C++
* **RAM (Random Access Memory):** Представляет собой последовательность пронумерованных ячеек со случайным доступом.
* **Оценка доступа:** Чтение и запись в любую из ячеек занимает одинаковое количество времени и никак не зависит от номера ячейки — выполняется за время $O(1)$.
* **Указатель:** Специальный тип данных, который хранит в себе адрес ячейки памяти (`int* pint;`, `long* plong;`, `double* pdouble;`, `int** ppint;`).

### Жизненный цикл данных в коде:
1. **Объявление (Declaration):** Введение имени переменной и её типа в программу.
   ```cpp
   int var; // Объявление
   ```
2. **Определение (Definition):** Выделение фактического места в памяти под переменную.
3. **Инициализация / Присвоение:** Задание начального или последующего значения переменной.
   ```cpp
   var = 0; // Определение/Инициализация -> Теперь состояние OK
   var = 1; // Присвоение значения -> Состояние OK
   ```

> [!WARNING] Важно: Неинициализированные переменные и Неопределенное Поведение (UB)
> Использование переменной сразу после объявления без явного присвоения значения влечет за собой чтение "мусора" из ячейки памяти.
> ```cpp
> int var;
> std::cout << var << '\n'; // Вызывает UNDEFINED BEHAVIOUR (UB)
> ```

## 3. Классификация типов данных и их физический размер

Физический размер типов зависит от архитектуры и стандарта, однако гарантируются следующие соотношения:

### 1. Целочисленные типы (Integral types)
* `short`: занимаемый размер $\ge 2$ байт.
* `int`: занимаемый размер $\ge 2$ байт, при этом $\text{sizeof}(int) \ge \text{sizeof}(short)$. На 4-байтовых системах $int \in [-2^{31}, 2^{31} - 1]$.
* `long`: занимаемый размер $\ge 4$ байт, при этом $\text{sizeof}(long) \ge \text{sizeof}(int)$.
* `long long`: занимаемый размер $\ge 4$ байт, при этом $\text{sizeof}(long long) \ge \text{sizeof}(long)$.
* `unsigned int`: беззнаковый тип, размер $\ge 2$ байт. Если $\text{sizeof}(unsigned\ int) == 4$, то диапазон значений $\in [0, 2^{32} - 1]$.

### 2. Типы с плавающей точкой (Floating-point)
* `float`: занимает $4$ байта, диапазон значений $\in [\pm 10^{-38}, \pm 10^{38}]$.
* `double`: занимает в два раза больше — $8$ байт ($2 \times 4$ байта).
* `long double`: расширенная точность.

### 3. Символьные типы
* `char`: занимает ровно $1$ байт по стандарту. Внутри ячейки хранится числовой код символа в кодировке ASCII.
  ```cpp
  char v = 'v';
  char v118 = 118; // 118 — код ASCII для символа 'v'
  char V = v + 'A' - 'a'; // Сдвиг по регистру в ASCII. Результат: 'V'
  ```

### 4. Логические типы
* `bool`: принимает значения `false` или `true`. Занимает $1$ байт.

### 5. Специальные типы
* `void`: пустой тип, не имеющий значений. Создать переменную типа `void` невозможно. Тем не менее, системный $\text{sizeof}(void)$ на ряде платформ может возвращать значение $1$.
* `std::nullptr_t`: тип для представления строго нулевого указателя (`nullptr`).

## 4. Явная типизация литералов и суффиксы

Литералы представляют собой константные значения, зафиксированные непосредственно в коде программы.

> [!TIP] Жесткое правило оформления кода из лекции
> Типизацию литералов суффиксами всегда выполняем строго **ЗАГЛАВНЫМИ БУКВАМИ**!

### Карта литералов и суффиксов:
* Целочисленные по умолчанию: `10` имеет тип `int`.
* Длинные целые: `1245453212L` или суффикс `l` (Используем `L`).
* Беззнаковые: `10U` или `10u` ($\to unsigned\ int$).
* Длинные беззнаковые: `10UL` или `10ul` ($\to unsigned\ long$).
* С плавающей точкой по умолчанию: `0.1` имеет тип `double`.
* Дробные одинарной точности: `0.1F` или `0.1f` ($\to float$).

### Системы счисления внутри литералов:
* Десятичные: `13`
* Шестнадцатеричные (суффикс `0x`): `0x123`
* Двоичные (суффикс `0b`): `0b1001`

## 5. Выражения, правила приведения типов и скрытые ловушки

Выражение представляет собой комбинацию операций и операндов (значений, переменных, вызовов функций). У всех операций есть строгие приоритеты.

### Арифметическое продвижение мелких типов (Integral Promotion)
Любые арифметические операции над типами данных, чей размер меньше чем у `int` (`char`, `short`), автоматически приводят операнды к типу `int` перед выполнением вычислений.
```cpp
short sx = 1;
char cx = 'a';
int ix = 1;

std::cout << sizeof(ix);        // Выведет: 4 (размер int)
std::cout << sizeof(ix + ix);   // Выведет: 4 (int + int = int)
std::cout << sizeof(sx);        // Выведет: 2 (размер short)
std::cout << sizeof(sx + sx);   // Выведет: 4! (продвижение short до int)
std::cout << sizeof(cx);        // Выведет: 1 (размер char)
std::cout << sizeof(cx + cx);   // Выведет: 4! (продвижение char до int)
```

### Вывод типов в смешанных выражениях:
* `'a' + 0` $\to$ результат `int`
* `'a' + 0L` $\to$ результат `long`
* `'a' + 0LL` $\to$ результат `long long`
* `'a' + 'a'` $\to$ результат `int` (из-за integral promotion)

### Общие правила неявного приведения типов:
1. Если один из операндов можно расширить до типа второго без потери точности, выполняется автоматическое расширение.
2. Если один из операндов относится к типу с плавающей точкой, то второй операнд принудительно приведется к типу с плавающей точкой.
3. Если один из операндов является **беззнаковым (unsigned)**, а второй **знаковым (signed)**, оба операнда автоматически приводятся к **беззнаковому** типу.

### Ловушки переполнения (Overflow)
* **Для знаковых целочисленных типов (`int`):** Любое переполнение знакового числа — это **Undefined Behaviour (Неопределенное Поведение)**. Компилятор имеет право оптимизировать код, исходя из предположения, что знакового переполнения случиться не может.
  ```cpp
  int x = 2'000'000'000;
  int y = 2'000'000'000;
  std::cout << x + y << '\n'; // UB! Знаковое переполнение. Выведет некорректное отрицательное число из-за сдвига знакового бита.
  ```
* **Для беззнаковых целочисленных типов (`unsigned int`):** Переполнение полностью легально. Происходит циклическая операция взятия остатка по модулю $2^{8 \times \text{sizeof}(type)}$.
  ```cpp
  unsigned int ux = 3'000'000'000;
  unsigned int uy = 3'000'000'000;
  std::cout << ux + uy << '\n'; // Легально. Произойдет сложение по модулю 2^32. Разность запишется по кругу.
  ```

### Ловушка точности чисел с плавающей точкой
Из-за невозможности точного представления некоторых дробей в двоичной системе счисления возникают погрешности.
```cpp
std::cout << (0.1 + 0.2 == 0.3) << '\n'; // Вернет FALSE!
```
* **Решение:** Проверять равенство через разность модулей и малую величину погрешности ($\epsilon$):
  ```cpp
  std::cout << (std::abs((0.1 + 0.2) - 0.3) < 0.0001) << '\n'; // Вернет TRUE
  ```

## 6. Логические и битовые операции

Необходимо строго разграничивать логические операции (вычисляющие общее условие) и побитовые операции (работающие поразрядно со структурой битов в памяти).

### Логические операторы
* `&&` — Логическое И.
* `||` — Логическое ИЛИ.
* `!` — Логическое отрицание.

### Побитовые операторы (Примеры из тетради):
* Побитовое И (`&`):
  $$6 \ \& \ 3 = 2 \implies (0110_2 \ \& \ 0011_2 = 0010_2)$$
* Побитовое ИЛИ (`|`):
  $$6 \ | \ 3 = 7 \implies (0110_2 \ | \ 0011_2 = 0111_2)$$
* Побитовый сдвиг влево (`<<`):
  $$6 \ll 1 = 12 \implies (0110_2 \to 1100_2)$$
* Побитовый сдвиг вправо (`>>`):
  $$6 \gg 1 = 3 \implies (0110_2 \to 0011_2)$$
  $$7 \gg 1 = 3 \implies (0111_2 \to 0011_2)$$

## 7. Условные конструкции и синтаксис ветвления

Реализуется с помощью конструкции `if`, `else if` и `else`.

### Общая синтаксическая структура:
```cpp
if (<boolean expression>) {
  <exec block>
} [else if (<another boolean expression>) {
  <another exec block>
}] [else {
  <exec block for case of no conditions passed>
}]
```

### Опасности при работе со строками и нулевым символом `\0`
В синтаксисе С-строк (массивов символов `char*`) символ `\0` является признаком завершения строки для стандартных потоков вывода.
```cpp
char* greet = "Hello, Vova!\n\0Goodbye, Vova!\n";
std::cout << greet; // Выведет только "Hello, Vova!", так как встретит маркер \0 и прекратит чтение.
```
