# C++. Введение: устройство программы, типы, память, условное выполнение

> [!info] Источники
> Конспект собран из методички курса и кода с семинара (`main.cpp`) — там, где семинарский код иллюстрирует то же самое другими примерами, я добавил их рядом.

---

## 1. Первая программа

Минимальная программа на C++:

```cpp
int main() {}
```

`main` — функция, с которой начинается выполнение программы. `int` означает, что функция возвращает целое число. Для `main` есть исключение: если выполнение дошло до конца тела без явного `return`, это равносильно `return 0;`.

```cpp
int main() {
    return 0;
}
```

`return` завершает функцию и возвращает значение — это **не** команда "напечатать число". Пока программа ничего не выводит на экран.

### Вычислить — не значит вывести

```cpp
int main() {
    return 2 + 2 * 2;  // вернётся 6, но на экране ничего не появится
}
```

Результат передаётся среде как **код завершения программы** (можно увидеть в Linux через `echo $?`). Ноль означает успешное завершение.

Чтобы реально что-то увидеть на экране, нужен вывод через стандартную библиотеку:

```cpp
#include <iostream>

int main() {
    std::cout << 2 + 2 * 2 << '\n';
    return 0;
}
```

- `std::cout` — стандартный поток вывода
- `<<` — отправляет значение справа в поток
- `'\n'` — символ перевода строки

> [!tip] Откуда взялись `iostream` и `std::`
> `<iostream>` — заголовочный файл с объявлениями для работы с потоками, подключается директивой `#include`. `std` — пространство имён стандартной библиотеки (не файл и не папка, а способ различать имена). Полное имя вывода — `std::cout`, "cout из пространства std".

### Кавычки меняют смысл

```cpp
std::cout << "2 + 2 * 2 = " << 2 + 2 * 2 << '\n';
```

Текст в кавычках `"..."` выводится как есть, компилятор не пытается вычислить формулу внутри строкового литерала. Несколько `<<` можно объединять в одну цепочку.

## 2. Как исходный текст становится программой

**Сборка и запуск — разные действия.** Файл `main.cpp` сам по себе не исполняемая программа, процессору нужны машинные инструкции.

```bash
g++ -std=c++20 main.cpp -o main   # сборка
./main                            # запуск
```

Во время сборки код `main` **не выполняется** — строка с `std::cout` сама по себе ничего не печатает на этапе компиляции.

### Этапы сборки

```
main.cpp -> main.ii -> main.s -> main.o -> main
```

| Этап | Что происходит |
|---|---|
| Препроцессор | обрабатывает директивы (`#include`, `#define`) |
| Компилятор | переводит C++ в ассемблерный код |
| Ассемблер | превращает ассемблер в объектный файл (машинный код) |
| Компоновщик (линковщик) | связывает объектные файлы и библиотеки, разрешает ссылки, создаёт исполняемый файл |

> [!tip] Зачем это знать
> Кнопка "Run" в IDE скрывает оба действия (сборку и запуск), из-за чего легко не заметить, что новая версия не собралась, и случайно запустить старый исполняемый файл.

### Что делает препроцессор

Кроме `#include`, препроцессор умеет **макроподстановки**:

```cpp
#define TWO 2

int main() {
    return TWO + TWO * TWO;  // после препроцессора: 2 + 2 * 2
}
```

`TWO` здесь — не переменная, у неё нет адреса и значения во время выполнения, это просто текстовая замена перед компиляцией.

`#include "my_header.h"` (кавычки — для своих заголовков) vs `#include <iostream>` (угловые скобки — для стандартных).

### Три вида ошибок

| Тип ошибки | Когда обнаруживается |
|---|---|
| Ошибка компиляции | пропущенная скобка, необъявленное имя — на этапе сборки |
| Ошибка выполнения | программа собралась, запустилась, но упала во время работы |
| Логическая ошибка | программа успешно работает, но считает не то, что нужно — **компилятор её не ловит** |

> [!warning]
> Успешная сборка не доказывает правильность программы — компилятор проверяет только правила языка, а не соответствие кода задумке.

## 3. Из чего состоит исходный код

### Ключевые слова и идентификаторы

`int` — ключевое слово (смысл задан языком), `main` — идентификатор (имя).

**Правила идентификаторов:**
- не могут начинаться с цифры
- содержат только буквы, цифры, подчёркивания (без пробелов и дефисов)
- не совпадают с ключевыми словами
- регистр важен (`Return` — уже не ключевое слово, а обычный идентификатор)

```cpp
vova              // OK
vovo4ka           // OK
vovo4ka_smirnov   // OK
vovo4ka-smirnov   // НЕ идентификатор (дефис)
4vova             // НЕ идентификатор (начинается с цифры)
return            // ключевое слово, нельзя использовать как имя
```

### Литералы

Целые числа можно писать в разных системах счисления:

```cpp
123      // десятичное: 123
0123     // восьмеричное: 83   (! начальный ноль меняет систему счисления)
0x123    // шестнадцатеричное: 291
0b101    // двоичное: 5
```

> [!warning] Начальный ноль — не украшение
> `123` и `0123` — это **разные** числа (десятичное и восьмеричное представления).

Другие виды литералов:

```cpp
3.1415926        // дробный (double)
'v'               // символьный (char) — одинарные кавычки
"hello, world"    // строковый — двойные кавычки
true, false       // логические (bool)
nullptr           // нулевой указатель (std::nullptr_t)
```

> [!important] `'v'` ≠ `"v"`
> Одинарные и двойные кавычки не взаимозаменяемы: `'v'` — символ, `"v"` — строка. У них разные типы и разное представление в памяти.

### Оператор, операция, выражение

- **Оператор (инструкция)** — описывает действие, например `return 0;`
- **Выражение** — задаёт вычисление, например `2 + 2 * 2`
- **Операция** — действует на операнды и входит в выражение, например `+`, `*`

```cpp
2 + 2;      // допустимо: оператор-выражение, но результат нигде не используется
```

### Комментарии

```cpp
// однострочный комментарий

/* многострочный
   комментарий */
```

Структуру блоков задают фигурные скобки `{}`, а не отступы. Точка с запятой ставится не после каждой строки, а завершает определённые конструкции (нужна после `return 0`, но не нужна после `#include <iostream>`).

## 4. Типы данных

Тип определяет: множество представимых значений, допустимые операции и способ интерпретации данных в памяти.

```cpp
std::cout << 11 / 4 << '\n';     // 2    (целочисленное деление)
std::cout << 11.0 / 4 << '\n';   // 2.75 (дробное деление)
```

### Основные типы

| Категория | Типы |
|---|---|
| Пустой | `void` (нельзя создать переменную такого типа) |
| Целочисленные | `short`, `int`, `long`, `long long`, `unsigned` варианты |
| С плавающей точкой | `float`, `double`, `long double` |
| Символьные | `char` |
| Логический | `bool` |
| Нулевой указатель | `std::nullptr_t` |

### Сколько памяти занимает число

```cpp
std::cout << sizeof(int) << '\n';
std::cout << sizeof(char) << '\n';  // 1, всегда (по определению)
```

Рабочая модель для примеров: 8-битный байт, 16-битный `short`, 32-битный `int`, 64-битный `long long`.

| Тип | Минимальная ширина | Часто встречается |
|---|---|---|
| `short` | 16 бит | 16 бит |
| `int` | 16 бит | 32 бита |
| `long` | 32 бита | 32 или 64 бита |
| `long long` | 64 бита | 64 бита |

> [!warning]
> `long` **не гарантирует**, что он шире `int` именно на вашей системе — гарантия только "не уже".

**Диапазоны:** для знакового целого шириной $N$: $-2^{N-1} \le x \le 2^{N-1}-1$. Для беззнакового: $0 \le x \le 2^N - 1$.

Для 32-битного `int`: от $-2\,147\,483\,648$ до $2\,147\,483\,647$. Для `unsigned int`: от $0$ до $4\,294\,967\,295$ — **тот же объём памяти**, просто без отрицательной части.

### Когда нужна конкретная ширина

```cpp
#include <cstdint>

std::int32_t count = 0;
std::int64_t total = 0;
std::uint32_t mask = 0;
```

Число в имени = ширина в битах. Границы конкретного типа — через `<limits>`:

```cpp
#include <limits>
std::numeric_limits<int>::min();
std::numeric_limits<int>::max();
```

### У литерала тоже есть тип

Целочисленный литерал без суффикса — первый подходящий тип из `int`, `long`, `long long`.

```cpp
10      // int
10U     // unsigned int
10L     // long
10LL    // long long
10UL    // unsigned long
10ULL   // unsigned long long

0.1     // double
0.1F    // float
0.1L    // long double
```

> [!tip] Пиши суффиксы заглавными буквами
> `10l` легко перепутать с `10` + цифра `1`. Правило: типизацию литералов выполняем только заглавными буквами.

Разделители разрядов апострофом ничего не меняют по значению, только читаемость:
```cpp
int x = 2'000'000'000;  // то же самое, что 2000000000
```

## 5. Переменные и хранение значений

**Переменная** — именованная область в памяти.

### Объявление, определение, инициализация, присваивание

```cpp
int x;      // объявление и определение (без значения)
x = 0;      // присваивание
x = 1;      // присваивание

int y = 2;  // инициализация (значение задаётся сразу при создании)
```

> [!important] `=` при инициализации ≠ операция присваивания
> Внешне выглядит одинаково, но это разные действия языка.

Варианты записи инициализации:
```cpp
int a = 1;   // копирующая
int b(2);    // конструкторная (круглые скобки)
int c{3};    // списковая (фигурные скобки)
int d{};     // значение по умолчанию — 0
```

### Почему нельзя читать незаданное значение

```cpp
int x;
std::cout << x << '\n';  // UB (неопределённое поведение) в C++20!
```

**Не** "какое-то случайное число" — язык вообще не даёт гарантий, что здесь будет читать. Всегда инициализируй переменную, если начальное значение уже известно: `int x = 10;`.

### Ввод данных

```cpp
int x = 0, y = 0;
std::cin >> x >> y;
std::cout << x + y << '\n';
```

`std::cin` — стандартный поток ввода, `>>` читает значение в переменную справа.

## 6. Как вычисляются выражения

### Арность, приоритет, ассоциативность

- **Арность** — количество операндов операции (унарный минус — 1, вычитание — 2)
- **Приоритет**: `2 + 2 * 2` = `2 + (2 * 2)` = 6
- **Ассоциативность**: вычитание группируется слева направо: `20 - 5 - 3` = `(20-5)-3` = 12; присваивание — справа налево: `x = y = 7` означает `x = (y = 7)`

> [!warning] Группировка ≠ порядок вычисления
> `(a + b) * (c + d)` не гарантирует, что сначала вычислится именно левая сумма. Пока выражения только читают значения, это незаметно — станет важно при побочных эффектах.

### Целочисленное деление

```cpp
11 / 4     // 2  (дробная часть отбрасывается к нулю)
11 % 4     // 3  (остаток)
-11 / 4    // -2
-11 % 4    // -3
```

Связь: $a = (a/b)\cdot b + a\%b$.

```cpp
double result = 11 / 4;     // 2   — деление уже целочисленное, потом преобразовано
double result = 11.0 / 4;   // 2.75 — дробный тип нужен ДО операции
```

### Переполнение и неопределённое поведение

Из `main.cpp`:
```cpp
int x = 2'000'000'000;
int y = 2'000'000'000;
std::cout << x + y << '\n';  // UB! сумма не помещается в 32-битный int
```

> [!important] Переполнение знаковых целых — UB, а не "перевернётся в минус"
> Для **беззнаковых** типов переполнение — это чётко определённая операция по модулю $2^{sizeof(type)}$. Для **знаковых** — неопределённое поведение (UB): компилятор ничего не обязан гарантировать, поведение может отличаться от запуска к запуску.

**Более широкая переменная слева не спасает:**
```cpp
long long result = x + y;  // всё ещё UB! x + y уже посчитано в int ДО присваивания
```

**Правильно** — привести тип до сложения:
```cpp
long long result = static_cast<long long>(x) + y;  // 4000000000, OK
```
или начать цепочку сложения с широкого литерала:
```cpp
long long first  = 0LL + x + y;  // OK — long long сразу
long long second = x + y + 0LL;  // UB — x+y уже посчитан в int
```

### Почему сумма двух `short` не обязана быть `short`

```cpp
short sx = 1, sy = 2;
std::cout << sizeof(sx) << '\n';       // 2
std::cout << sizeof(sx + sy) << '\n';  // 4 — тип результата уже int!
```

Это называется **целочисленное продвижение** (integral promotion): `short` и `char` перед арифметикой продвигаются до `int` (или `unsigned int`, если `int` не вмещает диапазон). `bool` продвигается в `int`: `false→0`, `true→1`.

### Общий тип арифметической операции

Порядок рангов для знаковых: `int → long → long long`. При смешении знакового/беззнакового правило "всегда побеждает беззнаковый" — **неверно**:

- Если ранг беззнакового ≥ ранга знакового → берётся беззнаковый
- Если знаковый тип шире и вмещает весь диапазон беззнакового → берётся знаковый
- Иначе → берётся беззнаковый вариант знакового типа большего ранга

Пример из `main.cpp`, иллюстрирующий смешение:
```cpp
std::cout << (10 + 3'000'000'000) << '\n';  // long (литерал 3 млрд уже long)
std::cout << (0.1f + 0.1) << '\n';          // double (float продвигается до double)
std::cout << (10u + 10) << '\n';            // unsigned int
std::cout << (1.0 + 10) << '\n';            // double
```

### Беззнаковая арифметика

Вычисления по модулю $2^N$:
```cpp
unsigned int ux = 3'000'000'000;
unsigned int uy = 3'000'000'000;
std::cout << ux + uy << '\n';  // не UB! это чётко определённая операция по модулю 2^32
```

> [!warning] "Определено" ≠ "правильно"
> Если результат прибавления единицы неожиданно стал нулём — поведение языка определено, но алгоритм всё равно может быть ошибочным.

## 7. Числа с плавающей точкой

Действительных чисел бесконечно много даже на отрезке $[0,1]$, а бит — конечное количество, поэтому **не все** числа представимы точно — их приходится округлять.

### Проблема 0.1 + 0.2

```cpp
std::cout << std::boolalpha;
std::cout << (0.1 + 0.2 == 0.3) << '\n';  // false!
```

`0.1`, `0.2`, `0.3` в двоичном представлении — бесконечные дроби, каждая округляется отдельно. Результат сложения приближений не обязан совпасть с приближением к `0.3`.

**Правильное сравнение** — через допуск (epsilon):
```cpp
#include <cmath>
double actual = 0.1 + 0.2;
double expected = 0.3;
const double epsilon = 0.0001;
std::cout << (std::abs(actual - expected) < epsilon) << '\n';  // true
```

> [!tip]
> `0.0001` — не универсальное число для любых сравнений, допуск зависит от задачи и масштаба величин.

С числами с плавающей точкой допустимы `+ - * /`, но **не** побитовые операции и не `%`.

## 8. Символы и строки

Символ — это число (код в ASCII), хранится как `char`:

```cpp
char v = 'v';
char v118 = 118;          // тот же символ 'v', код которого 118
char V = v + 'A' - 'a';   // 'V' — арифметика над символами работает через их коды
std::cout << v << V << v118 << '\n';
```

```cpp
char letter = 'v';
std::cout << static_cast<int>(letter) << '\n';  // 118
```

`sizeof(char) == 1` — это стандарт языка.

## 9. Сравнения, логика и биты

### Сравнения — тоже выражения с типом bool

```cpp
bool less = 5 < 6;  // true
5 == 6;  // false
5 != 6;  // true
```

> [!important] `==` — сравнение, `=` — присваивание
> ```cpp
> int x = 5;
> bool first  = (x == 0);  // false, x всё ещё 5
> bool second = (x = 0);   // false, но теперь x стало 0!
> ```

### Логические операции и короткое замыкание

```cpp
&&   // логическое И
||   // логическое ИЛИ
!    // отрицание
```

```cpp
int x = 12, y = 0;
bool large = y != 0 && x / y > 2;  // false, деление даже не вычисляется!
```

**Короткое замыкание** — гарантия языка, а не просто оптимизация: если слева от `&&` уже `false` (или слева от `||` уже `true`), правая часть вообще не вычисляется. Поэтому порядок условий важен: проверку деления на ноль всегда пишем **первой**.

### Побитовые операции — другая история

Работают с каждым битом отдельно, **не имеют** короткого замыкания:

```cpp
6 & 3 = 2     // 110 & 011 = 010
6 | 3 = 7     // 110 | 011 = 111
6 << 1 = 12   // сдвиг влево = ×2
6 >> 1 = 3    // сдвиг вправо = целочисленное /2
7 >> 1 = 3
```

> [!warning] `&`/`|` не путать с `&&`/`||`
> Замена `&&` на `&` в защитном условии с делением превратит корректный код в UB — побитовое `&` вычисляет **оба** операнда всегда.

## 10. Условный оператор `if`

```cpp
if (y != 0) {
    std::cout << x / y << '\n';
} else {
    std::cout << "Error\n";
}
```

Условие приводится к `bool`. Ветка `else` необязательна.

### Несколько вариантов

Из `main.cpp`:
```cpp
if (llx == 0) {
    std::cout << "This is zero!!!\n";
} else if (llx == 1) {
    std::cout << "This is one!!!\n";
} else {
    std::cout << "Oh no... this is neither zero nor one :(\n";
}
```

Условия проверяются сверху вниз, как только выбрана ветвь — остальные пропускаются. `else if` — это просто ещё один `if` внутри ветки `else`.

> [!warning] Независимые `if` — не то же самое, что цепочка
> ```cpp
> if (value == 0) { value = 1; }
> if (value == 1) { std::cout << "One\n"; }  // выполнится ОБА блока!
> ```
> Если второй `if` был бы `else if`, второй блок не выполнился бы.

### Частые ошибки

**Лишняя точка с запятой:**
```cpp
if (x > 0);              // это ПУСТОЙ оператор — if ничего не делает
{
    std::cout << "Positive\n";  // выполнится ВСЕГДА
}
```

**Потерявшийся else** (относится к ближайшему `if` без `else`):
```cpp
if (true)
    if (false) std::cout << "A\n";
    else std::cout << "B\n";  // выведется "B" — else относится к внутреннему if!
```

> [!tip] Всегда пиши фигурные скобки
> Экономия двух символов не стоит риска перепутать, к какому `if` относится `else`.

### Объявления внутри `if`

```cpp
if (int x = 0) {
    std::cout << x << '\n';
} else {
    std::cout << "Zero\n";  // выполнится, т.к. x==0 -> false
}
```

Переменная доступна в обеих ветках, но недоступна после всего оператора.

## Бонус из семинара: указатели и модель памяти (предварительно, разберём подробнее позже)

**Модель памяти C++ (RAM):** последовательность пронумерованных ячеек со случайным доступом за $O(1)$ — чтение/запись в любую ячейку занимает одинаковое время независимо от номера.

**Указатель** — тип данных, хранящий адрес ячейки памяти:

```cpp
int var = 0;
int* pint = &var;   // pint хранит адрес переменной var
```

```cpp
long long lly = 0;
long long *plong, llx;
plong = &llx;   // указателю присвоили адрес переменной llx
```

`&x` — операция взятия адреса переменной `x`. Из `main.cpp` видно, что адреса разных переменных отличаются на несколько байт (соседние ячейки в стеке):
```cpp
std::cout << pint << ' ' << &ix << '\n';
// var <=> 140724333772844
// ix  <=> 140724333772848
```

## Вопросы на подумать (из методички)

> [!question] 1. Одно число, разные способы вычисления
> Пусть `int` 32-битный, обе переменные содержат два миллиарда. Какие строки корректны?
> ```cpp
> int x = 2'000'000'000;
> int y = 2'000'000'000;
> long long a = x + y;                                  // ?
> long long b = static_cast<long long>(x + y);           // ?
> long long c = static_cast<long long>(x) + y;           // ?
> long long d = x + 0LL + y;                             // ?
> ```
> *Подсказка: смотри раздел 6.4 выше — важно, **когда** появляется широкий тип в цепочке вычислений.*

> [!question] 2. Данные и их вывод
> Что выведется и почему видимый текст и размер литерала — не одно и то же?
> ```cpp
> std::cout << "A\0B" << '\n';
> std::cout << sizeof("A\0B") << '\n';
> std::cout << sizeof('A') << '\n';
> ```
> *Подсказка: `\0` — это символ с кодом 0 ("конец строки" для C-строк), но `sizeof` считает байты в литерале, включая его.*

## Итог лекции

- Программа собирается (препроцессор → компилятор → ассемблер → линковщик), а не просто "запускается"
- У каждого значения есть **тип**, определяющий диапазон, операции и интерпретацию в памяти
- Переполнение знаковых целых — UB, беззнаковых — арифметика по модулю $2^N$
- `short`/`char` перед арифметикой проходят **целочисленное продвижение** до `int`
- `0.1 + 0.2 != 0.3` — числа с плавающей точкой сравнивай через допуск (epsilon), а не `==`
- `&&`/`||` — короткое замыкание, `&`/`|` — нет
- `if`/`else if`/`else` — цепочка проверяется сверху вниз, `else` относится к ближайшему `if`; лишняя `;` после условия — частая ловушка
