# ML Roadmap

Публичный дневник подготовки к стажировке в ML / Data Science. Здесь я собираю решённые задачи, ноутбуки и проекты и честно показываю, что уже сделано, а что ещё нет.

## Обо мне

Первокурсник ПсковГУ (направление «Математика и компьютерные науки»), параллельно занимаюсь по курсу алгоритмов МФТИ. Цель: пройти отбор на ML-стажировку в крупную IT-компанию. Реалистичный горизонт: отборы 2027-2028.

## Что в репозитории

| Папка | Что внутри |

## План

- **Этап 0:** Git, терминал, venv, Jupyter. *В процессе.*
- **Этап 1:** алгоритмы (сложность, массивы, сортировки, бинарный поиск, рекурсия, деревья), numpy, pandas, matplotlib, SQL.
- **Этап 2:** основы ML (регрессия, деревья, ансамбли, метрики, кросс-валидация), scikit-learn, CatBoost/XGBoost; первый проект на Kaggle-данных.
- **Этап 3:** PyTorch, второй проект (тексты или изображения), по желанию сервис на FastAPI.
